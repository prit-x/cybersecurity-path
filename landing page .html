Why I Built This

I created this repository primarily as my own personal study hub — a place to store all my cybersecurity notes, learning resources, code snippets, and project documentation in one organized location.

But I realized — if it helps me, it can help others too. So I'm making everything public and free. Whether you're a beginner just starting out or someone looking for structured resources, feel free to explore, learn, and use whatever you find here.

This is a living project. I keep adding new paths, resources, and projects as I learn. Star the repo if you find it useful — it keeps me motivated to add more.
