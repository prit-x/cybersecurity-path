Part 2: Detailed Module Breakdown
Everything you need to learn, where to learn it, and exactly how long it takes
🐧
SKILL 01 · PHASE 1

Linux Fundamentals

The OS used by 99% of hackers and servers
⏱ 2 Weeks
What to Learn
  • Navigation (cd, ls)
  • File Manipulation (cat, grep)
  • User Permissions (chmod)
  • Package Management
  • Basic Bash Scripting
Where to Learn
🎯
TryHackMe — Linux Fundamentals Part 1, 2 & 3 (Free)
 🎮
OverTheWire: Bandit — Learn Linux by playing a game
Specific Focus

Master the Terminal. Do not use the graphical interface (mouse). Learn how to use the grep command to search for text.

💡 Pro-Tip: Don't try to memorize every command. Instead, learn how to use the man command (manual) or Google to find what you need.
➡️ Install Kali Linux on a Virtual Machine (VirtualBox) and start using it for daily tasks. Then move to Networking.
🌐
SKILL 02 · PHASE 1

Networking Foundation

How computers talk to each other
⏱ 3 Weeks
What to Learn
  • OSI Model
  • TCP vs UDP
  • IP Addressing (IPv4/IPv6)
  • Subnetting
  • MAC Addresses
  • Common Ports (80, 443, 22, 21)
  • DNS & DHCP
Where to Learn
🎯
TryHackMe — Pre-Security Path → Network Fundamentals
 📺
YouTube: NetworkChuck — Free CCNA playlist (First 10 videos)
Specific Focus

Deeply understand Ports and Protocols. Understand exactly what happens when you type google.com and press enter.

💡 Pro-Tip: Download Wireshark on your normal computer and just watch the packets flying around. It makes the invisible network visible.
➡️ Connect your Linux & Networking knowledge by learning how to scan networks using Nmap.
🖥️
SKILL 03 · PHASE 1

Web & Internet Basics

Before hacking a website, know how it's built
⏱ 2 Weeks
What to Learn
  • HTTP Requests (GET, POST)
  • HTTP Responses (200, 404)
  • Cookies & Sessions
  • JSON
  • Basic HTML / JavaScript
Where to Learn
🎯
TryHackMe — Pre-Security Path → How The Web Works
 📄
MDN Web Docs — HTTP Basics
Specific Focus

Focus heavily on HTTP Headers and Cookies. This is where most web vulnerabilities hide.

💡 Pro-Tip: Right-click any website → "Inspect Element" → "Network" tab → Refresh. Look at all the requests your browser is making!
➡️ Set up Burp Suite (the ultimate web hacking tool) to intercept web traffic.
🕷️
SKILL 04 · PHASE 2

Tool Mastery — Burp Suite

The sniper rifle of a web hacker
⏱ 1–2 Weeks
What to Learn
  • Proxy Interception
  • Repeater
  • Intruder
  • Decoder
Where to Learn
🌐
PortSwigger Web Academy — Burp Suite Basics (by the creators)
 🎯
TryHackMe — Burp Suite Module
Specific Focus

Master the Repeater tab. Capture a request, change variables (e.g. id=1 → id=2), and send it again.

💡 Pro-Tip: Configure Firefox with the FoxyProxy extension to easily switch your traffic into Burp Suite.
➡️ You have the foundation and the tools. Time to learn actual vulnerabilities.
💥
SKILL 05 · PHASE 2 — THE BIG ONE

Web Vulnerabilities (OWASP Top 10)

The actual hacking phase — Take your time here
⏱ 8–10 Weeks
Vulnerabilities to Master
SQL Injection (SQLi) Cross-Site Scripting (XSS) IDOR Command Injection Broken Authentication
Specific Focus

Focus first on IDOR and XSS. They are the most common and easiest to find for beginners.

Where to Learn
⭐
PortSwigger Web Academy — The absolute BEST free resource on the internet
 📺
YouTube: Rana Khalil — Walkthroughs of PortSwigger labs
💡 Pro-Tip: NEVER use automated scanners (like Acunetix or Nessus) right now. Learn to find bugs manually. Automated tools make you lazy; manual hacking makes you a master.
🏆 You are now ready to achieve your End-of-Year Goal!

Part 3: Your End-of-Year Achievement Plan
Choose ONE path based on the time you have left in the year
A
Option A · Hacker Resume Builder

Capture The Flag (CTF)

The Goal: Rank in the top 20% on a major CTF platform and prove your skills in a competitive environment.

Create an account on PicoCTF.org

Solve the Web Exploitation and General Skills categories

Also practice on TryHackMe and HackTheBox

📄 Proof: PicoCTF profile link on your LinkedIn & resume
B
Option B · Real World Impact

Bug Bounty Hunter

The Goal: Find a valid vulnerability on a real company and get a "Hall of Fame" mention — no experience needed.

Sign up for HackerOne or Bugcrowd

Look for VDPs (Vulnerability Disclosure Programs) — no money, but points & recognition

Pro hackers ignore VDPs (no cash) → leaving easy bugs for beginners like you

🏅 Proof: HackerOne Reputation points / Hall of Fame emails
C
Option C · Professional Credentials

Certification (eJPT)

The Goal: Pass the eJPT (eLearnSecurity Junior Penetration Tester) — a respected, practical certification.

Enroll in the free PTS course by INE (Penetration Testing Student)

Study all the material thoroughly — labs included

Pay ~$200 for the exam voucher when ready

🎓 Proof: A highly respected practical certification on your resume

5 Golden Rules for This Roadmap
Follow these or you will spin in circles for months
01
Rule of One

Master ONE topic before moving to the next. Do not learn Linux and Web Hacking on the same day.

02
The 70/30 Rule

Spend 30% of your time watching/reading, and 70% actually typing commands and hacking in labs.

03
Note-Taking is Mandatory

Use Notion or Obsidian. Write every command you learn. You will forget. Your notes = your personal hacking manual.

04
The Struggle Timer

When stuck on a lab, set a 30-minute timer. You are NOT allowed to Google the exact answer until the timer goes off.

05
Stay Legal — Always

NEVER point any hacking tool at a website/network you do NOT own or have explicit permission to test.

🚨
Only Hack on Authorized Platforms

NEVER use Nmap, Burp Suite, or any hacking tool on a website or network you do not own or do not have explicit written permission to test. Unauthorized hacking is a criminal offence in every country. Always stay within the boundaries of these safe, legal environments:

✅ TryHackMe ✅ HackTheBox ✅ PortSwigger Web Academy ✅ PicoCTF ✅ Authorized Bug Bounty Programs
